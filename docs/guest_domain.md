# ゲストコンテキスト

## 責務

- ゲストに会場の状況（混雑・行列・天候）とスタッフメッセージを表示
- 上流（観測・スタッフ間コミュニケーション）が push した内容を読み取りモデルとして自 DB に保持し、アクセス時は自 DB のみで応答（都度の外部問い合わせをしない）
- ゲスト向け表示の組み立て（表示名の付与・文言化）を担う
  push される状況は ID と数値のみで、表示名はグラフ編集から取得した複製を使って本コンテキストが付与する
- 案内マップを表示する
  グラフ、案内マップレイアウト、混雑状況の3つから組み立て、QR 設置箇所の配置位置を現在地にする
- 誘導提案は表示しない
  提案はスタッフ向けであり、ゲストへの誘導情報はスタッフがゲスト向けメッセージとして手動配信する

## ドメインモデル

| 語 | 英語 | 内容 |
|---|---|---|
| ゲスト | Guest | 誘導対象<br>多くは未認証でQR経由 |
| QR（設置箇所） | Location QR | 設置箇所・種類ごとに発行される URL の QR<br>設置箇所の定義とグラフ紐づけの正本はグラフ編集（QR設置箇所）<br>人数カウント源（ページ表示時に設置箇所単位で計上）<br>動的化（時間で変わる偽造対策）は将来導入 |
| ゲスト用ページ | Guest Page | 組み換え可能なコンポーネント群で構成されるページ<br>各コンポーネントは Guest Service に集約された API から読み取りモデルの内容を個別に取得<br>URL（設置箇所×種類）がページ構成を決める |
| ページ構成 | Page Composition | URL（設置箇所×種類）に対応するコンポーネントの組み合わせ<br>本コンテキストの設定として保持 |
| ゲスト向け読み取りモデル | Guest Read Model | 上流の push を集約した自 DB 上の複製<br>正本は上流（状況＝観測／メッセージ＝スタッフ間コミュニケーション／表示名＝グラフ編集） |
| 案内マップ | Guide Map | 現在地から目的地までの経路を示すゲスト用ページのコンポーネント<br>グラフ、案内マップレイアウト、混雑状況の3つから組み立てる<br>ゲストに渡すグラフは、案内マップレイアウトが参照するポイントとグループの ID とラベルだけ |
| 案内マップレイアウト | Guide Map Layout | ゲスト向けの地図を描くための情報<br>部品（場所・エリア・線・文字）が `point_id`・`route_id`・`group_id` でグラフを参照し、面はグラフのグループ<br>グラフエディタのレイアウトとは別物で、略して「レイアウト」と呼ばない<br>正本はグラフ編集（グラフ版に含まれる） |
| 階移動手段 | Connector | 案内マップレイアウトの場所のうち、階段・エスカレーター・エレベーター<br>同じ連絡キーを持つもの同士が面をまたいでつながる |
| 線 | Line | 案内マップレイアウトの折れ線の部品<br>グラフのルートとは別物で、ルートを指すときは `route_id` で参照する |
| 案内マップエディタ | Guide Map Editor | 案内マップレイアウトを作るツール |
| 現在地 | Current Location | 案内マップの経路の起点<br>開いた QR の設置箇所の配置位置が指すポイントから決め、決まらなければ案内マップレイアウトの既定の出発地 |
| 混雑回避経路 | Crowd-Avoiding Route | ゲスト向けの混雑状況からゲスト用ページが計算する、混雑を避けた経路<br>誘導提案ではなく案内<br>地図に描く線は経路線と呼ぶ |
| サイネージ | Signage | ゲスト向け映像表示（行列のAR描画含む）<br>同じ読み取りモデルから描画<br>リアルタイム性は専用要件に先送り |

## ドメインイベント

| イベント | 英語 | 契機 |
|---|---|---|
| 動的QR更新された | RotatingQrRefreshed | 将来導入（QR の動的化＝偽造対策） |
| ゲスト向け状況更新された | GuestViewUpdated | 観測からの状況 push 受信 |
| ゲスト向けメッセージ更新された | GuestMessageUpdated | スタッフ間からのメッセージ push 受信（スタッフの手動配信） |
| ゲストがページを開いた | GuestPageOpened | QR（設置箇所・種類ごとの発行 URL）経由のアクセス |
| QR由来の人数計上された | GuestCountedViaQr | ページ表示時に設置箇所単位で計上（コンポーネント呼び出しごとではない） |
| アクセス時スナップショットが返された | GuestSnapshotServed | ページ表示（各コンポーネントが読み取りモデルから取得）の単位で発生 |
| サイネージが更新された | SignageUpdated | 読み取りモデルの描画更新 |

## 不変条件

- ゲスト個人へのリアルタイム配信をしない（ゲストへはアクセス時 pull）
- 読み取りモデルは複製であり正本は上流
- push は at-least-once として受信側が冪等に処理し、起動時と定期に上流と突き合わせて欠落を復旧する（配信の再試行はブローカーへ委譲）
- 表示名の付与は本コンテキストが担う（上流は表示名・文言の語彙を持たない）
- ゲストは未認証が基本で個人追跡・割当なし
- 並び先案内も集約案内のみ
- 誘導提案を直接表示しない（スタッフの手動配信を介する）
- ゲスト向けの RPC はゲストに必要な情報だけを返す（未認証で誰でも呼べるため）
